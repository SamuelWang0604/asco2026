ASCO 2026 全瘤种概览

深度数据分析报告
数据范围：ASCO 2026 年会全部摘要  |  分析日期：2026年5月  |  总计 3,440 项研究

01执行摘要

核心洞察
  • 免疫+靶向双驱格局确立——Chemotherapy (1018) 与 Targeted Therapy (1013) 并列双冠，Immunotherapy (805) 紧随其后，三大治疗模式合计占治疗类型计数 73%，ADC (250) 与 Bispecific Antibody (160) 成长为第二梯队。
  • Phase 3 仅占 5.8%，转化瓶颈显著——201 项 Phase 3 研究集中于 GU Cancer (38)、Hematologic (27)、GI Cancer (24)，而 695 项 Phase 1 的管线能否兑现临床价值，将决定未来 3-5 年的竞争格局。
  • 中国参与度 28.6%，Phase 1 占比 29.7%——中国 985 项参与研究中 Phase 1 达 292 项，Phase 3 仅 54 项；GI Cancer 中国参与率最高达 42.4%，但 Melanoma 仅 13.8%，差异显著。
  • HER2² 与 TP53 成为最高频靶点——HER2² 出现 30 次（跨瘤种以乳腺癌为核心），TP53 出现 25 次（泛瘤种），CD19 (13) 反映细胞治疗在血液学领域的持续活跃。
  • ADC + Bispecific 进入爆发期——ADC 250 项跨 10 个瘤种，Bispecific Antibody 160 项在 NSCLC、GI Cancer、GU Cancer 中密集布局，双抗联合化疗/免疫成为新范式。

08结论与建议

五大结论

结论一：IO+Targeted 双驱格局不可逆
Chemotherapy 与 Targeted Therapy 并列双冠（各约 1,013 项），Immunotherapy 805 项紧随，三大模式合计 73%。ADC (250) 和 Bispecific (160) 已成长为第二梯队，正在重塑联合治疗范式。传统"化疗+IO"骨架正被"ADC+IO"和"双抗+化疗"补充甚至替代。
结论二：Phase 3 转化率是关键瓶颈
695 项 Phase 1 仅 201 项 Phase 3，转化率约 29%。GU Cancer Phase 3 占比最高 (13.2%)，而 Supportive Care (0.7%)、Prevention (0%) 的后期研究极度匮乏。大量早期管线面临同质化竞争，能否推进至注册研究将决定未来竞争格局。
结论三：中国从"参与"走向"竞争"
中国 28.6% 的参与度已不容忽视，但 Phase 1 占比 29.6% vs Phase 3 仅 5.5%，早期管线占绝对主导。Ivonescimab (HARMONi-6) head-to-head 击败 Tislelizumab+Chemo，Cadonilimab、QL1706 等原研双抗进入全球竞争，标志着中国从临床试验"参与方"向"竞争者"转变。
结论四：罕见靶点从泛瘤种到精准的分化
TP53 (25项) 领跑泛瘤种 Basket 研究，但临床转化率存疑。与之对比，RET fusion (Pralsetinib/Selpercatinib)、DLL3 (Tarlatamab/ZL-1310)、IDH (Vorasidenib) 等精准靶点已在 Phase 3 获得确证。"宽靶点筛患者"的 Basket 模式与"窄靶点深挖掘"的精准模式将长期并存。
结论五：ADC+IO 成为年度主旋律
EV+Pembro (GU)、Sac-TMT+Pembro (NSCLC/Gynecologic)、Dato-DXd (Breast) 等 ADC+IO 组合在 Phase 3 中反复验证。ADC 作为"靶向化疗"与 IO 的协同机制已被广泛认可，下一波竞争将围绕"哪个ADC + 哪个IO + 哪个瘤种"展开。

战略建议

  1. 优先布局 ADC+IO 联合方案——ADC (250项) 已成不可忽视的治疗支柱，建议在现有 IO 骨架上叠加 ADC，优先 GU Cancer (EV 验证路径)、NSCLC (Sac-TMT 验证路径)、GI Cancer (T-DXd 验证路径) 三个瘤种。
  2. 关注双抗从 Phase 1 到 Phase 3 的转化窗口——Bispecific Antibody 160 项研究中大量处于 Phase 1，Ivonescimab、Tarlatamab 已证明 head-to-head 策略可行。建议在 PD-1/VEGF、DLL3×CD3 两条路径上加速注册研究设计。
  3. 中国策略：深耕高参与率瘤种、补位低参与率领域——GI Cancer (42.4%) 和 H&N Cancer (39.3%) 是中国优势阵地，应巩固。同时 Melanoma (13.8%)、CNS (24.3%) 存在显著空白，可通过国际多中心合作快速补位。
  4. TP53 靶点需谨慎评估——25 项研究看似火热，但泛瘤种 Basket 路径的转化率存疑。建议在布局 TP53 靶点时，明确分子亚群（如特定突变类型、组合标志物）以提高临床成功率。
  5. 伴随诊断与疗效预测标志物是差异化关键——HER2-low/ultra-low、CLDN18.2 表达阈值、PD-L1 CPS/TPS 等生物标志物的标准化将直接影响患者选择和临床结果。建议在临床开发早期同步投入 CDx 开发。
